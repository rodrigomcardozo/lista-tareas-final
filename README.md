
# Lista de Tareas con Código Secreto

Trabajo Final - Programación Móvil II

## Descripción

Aplicación móvil desarrollada con React Native y Expo
que permite administrar una lista de tareas personales.

El proyecto corresponde a la opción 2 del trabajo final
de Programación Móvil II.

## Funcionalidades

- Agregar nuevas tareas.
- Visualizar las tareas registradas.
- Marcar tareas como completadas.
- Reabrir tareas completadas.
- Eliminar tareas.
- Activar una función oculta mediante un código secreto.
- Consultar contadores de tareas.
- Filtrar tareas pendientes y completadas.
- Validar que no se agreguen tareas vacías.
- Elegir entre 20 íconos para identificar las tareas.
- Asignar prioridades alta, media y baja.
- Ordenar automáticamente las tareas según prioridad y estado.
- Visualizar cinco tareas de ejemplo al iniciar la aplicación.
- Utilizar una interfaz moderna con colores e íconos.


## Tecnologías utilizadas

- React Native
- Expo SDK 58
- JavaScript

## Conceptos aplicados

- useState
- TextInput
- Button
- Eventos y funciones
- Arrays y objetos
- map() y filter()
- Renderizado condicional
- Cálculos sobre arrays

## Instalación y ejecución

1. Clonar o descargar este repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar `npm install`.
4. Ejecutar `npx expo start`.
5. Abrir la aplicación desde Expo Go en Android.

## Consideraciones

Los datos se almacenan temporalmente mediante estados
locales de React Native.

No se requiere base de datos, backend ni conexión
a servicios externos.
